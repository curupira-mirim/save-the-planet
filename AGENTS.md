# Rotina global de skills

No início de todo chat, examine as skills disponíveis e use a skill pertinente antes de executar a tarefa. Não carregue indiscriminadamente skills não relacionadas.

Para qualquer pedido que audite, crie, altere ou publique uma landing page ou site público, use obrigatoriamente a skill `landing-discovery`. Combine-a com `copywriting`, `design` ou `viral-product-strategist` apenas quando o pedido também envolver, respectivamente, texto de conversão, interface/identidade visual, ou estratégia de oferta/conversão.

Para um pedido de publicar um projeto local em um repositório GitHub recém-criado, após o usuário fornecer a URL do repositório, use obrigatoriamente a skill `github-repo-bootstrap`.

Quando o usuário solicitar “commit e push”, “commit and push” ou equivalente, use obrigatoriamente a skill `commit-and-push`.

Priorize sempre as instruções explícitas do usuário. Skills orientam o método; não autorizam mudanças externas, deploys, compras, mensagens ou conteúdo factual não confirmado.
